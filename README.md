# Sistema Inteligente de Parqueo

## Descripción

Proyecto universitario grupal enfocado en el diseño y desarrollo de un sistema inteligente para la gestión de estacionamientos. Integra conceptos de programación, bases de datos, autómatas y electrónica digital.

## Objetivo

Desarrollar una solución tecnológica que permita representar y gestionar procesos relacionados con el estacionamiento de vehículos.

## Áreas tecnológicas

- **Programación:** lógica computacional y desarrollo de la solución.
- **Bases de datos:** diseño y gestión de la información.
- **Autómatas:** aplicación de conceptos de estados y transiciones.
- **Electrónica digital:** integración de conceptos electrónicos relacionados con el sistema.

## Tecnologías

Las tecnologías y herramientas específicas se documentarán conforme avance el desarrollo del proyecto.
